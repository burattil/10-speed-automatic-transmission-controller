# EcoCAR 10-Speed Automatic Transmission Controller

## Project Overview
This project was completed as part of the EcoCAR Innovation Challenge's Propulsion Controls & Modelling sub-team development challenge at McMaster University. 

The objective was to develop a controller for a simulated 10-speed automatic transmission using MATLAB/Simulink and Stateflow. The controller determines gear selection and manages transmission operating states based on vehicle conditions, while satisfying safety, performance, and drivability requirements. 

The vehicle plant and simulation model were provided as part of the challenge. My work focused on the development of the transmission controller, defining requirements, and verifying its functionality.

## My Contributions
- Developed transmission control logic to manage gear selection and transitions between Park, Reverse, Neutral, and Drive states.
- Implemented gear-shifting logic for a 10-speed automatic transmission based on vehicle operating conditions.
- Incorporated safety constraints to prevent invalid gear selections and maintain engine operation within specified RPM limits.
- Developed requirements to define controller behaviour
- Created test cases in Simulink Test to evaluate controller functionality under various driving conditions.
- Investigated controller performance against vehicle acceleration and drivability requirements.
